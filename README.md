# Monitoramento do Rio Una

## Sobre o projeto
Este projeto tem como objetivo desenvolver um sistema de monitoramento preventivo do Rio Una, na região de Palmares - PE.

## Problema
O Rio Una pode apresentar aumento do nível da água em períodos de chuva, causando enchentes e colocando a população em risco.

## Objetivo
Criar um sistema que permita acompanhar o nível da água do rio e emitir alertas para ajudar a prevenir acidentes e informar a população sobre possíveis enchentes.

## Funcionalidades planejadas
- Monitoramento do nível do rio.
- Exibição da situação atual do rio.
- Alertas de risco de enchentes.
- Interface simples para consulta das informações.
